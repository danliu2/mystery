# 狼人杀游戏详细设计

版本：1.0；设计日期：2026-10-04；状态：设计基线；已于同日按后续授权完成桌面原型，实际状态见第 9 篇。

## 目标与约束

为一位真人玩家提供与具有持续人格、外貌和跨局记忆的 AI 朋友共同参加狼人杀的桌面体验。Node.js 承担运行时，Electron 承担窗口；Host 完全由确定性代码实现，Creator 和 Player 共用一个 OpenAI 格式模型服务。任何参与者只能获得角色合法视野；游戏效果来自讨论与策略，而非全知模型或主持人自由裁决。

首次交付为详细设计文档。源需求为本地私有设计，本文仅抽取产品需求，不复制私有目录内容或任何凭据；没有读取凭据文件、调用付费模型、创建代码或执行安装。当前目录尚未初始化 Git，因此首次设计交付没有提交。后续用户授权本地 Git 初始化和代码开发，见 [开发状态](09_development_status.md)。

## 设计取舍

推荐“确定性规则内核 + 逐角色信息投影 + 独立 LLM 决策”，比让 LLM 主持更能控制合法动作、重放及保密；比纯脚本 AI 更有语言和人格变化。暂不引入多进程智能体框架或外部 Agent 平台：所有 AI 仍是独立上下文，服务共享并不共享记忆。

完整 12 人模式保留预女猎白与警长机制。6–14 人均有固定配置，非 12 人配置是项目实验预设，不声称是统一官方规则或已验证平衡。无狼人私聊是源需求的明确变体；女巫自救、死亡技能与终局顺序等争议也在规则文档中固定。默认 12 人，入门推荐 6 人。

不实现语音、联网多人、其他剧本、头像生成、商店、排行榜、自动修改模型权重；保留语音和游戏插件接口。设计阶段未进入代码实现；后续授权后的实现记录见 [开发状态](09_development_status.md)。

# 开发状态与验证记录

日期：2026-10-04；版本：0.1.0；状态：可本地运行的桌面原型。

用户在详细设计交付后明确授权初始化本地 Git 并开始实际开发。仓库使用 `development` 分支，设计基线和实现分阶段提交，未配置远程、未推送。没有读取私有凭据或调用真实付费服务。

## 交付范围

设计中的主游戏流程已经落地：确定性 Host、角色权限投影、6–14 人配置、警长与各角色技能、事务存储、持续人格朋友、OpenAI 格式网关，以及 React/Electron 桌面界面。提供离线演示和模型两种模式；界面只获得真人视图，结束后才能读取全知复盘。语音仅保留接口。

代码入口为 `src/main/index.ts`，规则在 `src/domain`，模型与人格在 `src/llm` 和 `src/agents`，存储在 `src/storage`，界面在 `src/renderer`。角色和配置资源位于 `resources/games/werewolf`，可编辑资源在开局时校验并固化到存档。

原设计文档 01–07 保留为设计基线；涉及“尚未实现”的描述代表首次设计交付时间，本文件记录实际实现与边界。启动方式见根目录 README。

## 审查裁定与修复

独立代码审查发现的严重和重要问题全部处理，并用回归测试验证：

| 问题 | 裁定与结果 |
| --- | --- |
| 对局 ID 暴露发牌随机种子 | 修复：公开 ID 改为独立 UUID，种子保留在主进程私有状态 |
| 非行动玩家通过猎人窗口标签推断隐藏身份 | 修复：非行动者统一获得普通白天阶段，私有技能窗口不公开 |
| 实时模型请求数可用于推断隐藏角色数量 | 修复：进行中的对局不公开请求/Token 统计，终局才显示 |
| 更换朋友池后读取旧存档无法匹配原角色 | 修复：存档包含原池快照，缺失人物时要求玩家明确恢复原池，并备份现有池 |
| 写盘失败后丢弃已生成候选动作 | 修复：保留候选状态，暂停并在恢复时先重试持久化，避免重新生成决策 |
| 终局朋友池保存失败导致下一局入口锁死 | 修复：始终释放收尾状态；重启读取终局存档时幂等补充模板经验 |

额外修复了模型模式与已使用预算在读档后丢失的问题，以及暂停无法取消终局模型反思的问题。反思仅使用各朋友自身合法视图，模板经验先保存；完整主持人事实不会自动成为跨局记忆。

审查的三个次要问题暂缓，均不影响规则裁决：暂停/切页可能重播当前段落；公开票型已列个人选择但没有额外汇总加权总票数；失败请求的 Token 估算可能不完整。警长票权仍由规则内核正确计入。后续按实际体验安排修复。

审查未对模型战略水平、真实服务兼容性、发布包与 Finder 双击兼容性作结论；粗粒度等待时间也可能留下推断线索。目前只有本机 Electron 启动和 UI 自动化证据，不将这些未验证项视为通过。

## 已知限制与后续方向

- 尚无签名、打包安装、自动升级、语音、多人联网或其他剧本。
- 尚未自动限制存档总数或清理旧事务；用户可在存档页删除对局，磁盘空间需自行管理。
- 模型仍可能受玩家发言中的提示注入影响策略；结构化校验与主进程权限阻止其越权行动，不保证推理质量。
- 发言逐字展示属于表现层，暂停后重播段落不重新执行已经接受的规则动作。
- 全知复盘包含部分原始结构化事实，属于可用原型，后续可以改进玩家可读性。
- 尚未在全新机器从零安装、各平台打包或所有真实服务上完成验证。安装下载失败可重试运行时安装命令。

后续应先用真实服务进行小样本合法性和体验评估，再扩大策略评测与平衡调整；演示模式和自动模拟可持续用于规则回归。

# 即时显示与真实 LLM 后端

日期：2026-10-04。本文记录用户体验反馈后对版本 0.1.0 的增量修改。

## 显示时序

默认立即显示完整新文本，立即确认当前可见事件；自动滚动使用即时定位，AI 调度取消原来的 60ms 延时。不再让文本播放人为等待未来语音。原慢速、标准和快速选项保留为用户主动选择，当前默认是立即显示。

模型完成后仍先写入存档，再发布投影后的事件。实际网络响应和可靠写盘耗时不可通过刷新策略消除；不会先显示尚未被规则接受的模型动作。

## 提示词与服务配置

提示词统一位于 `resources/prompts/werewolf/`，包括六种角色、共用 Player、规则摘要、Creator、反思、格式修复和连接测试。模板与可用占位符详见该目录 README。主进程使用绝对资源路径，每次请求重新读取；存档记录实际消息的 SHA256，修复请求也单独记录指纹。

运行程序仍读取根目录 `api_key.env`，私有源配置是 `secret/api_key.env`。本次联调用文件操作复制私有配置到被 Git 忽略的运行配置，追加经服务 `/models` 验证存在的 `deepseek-flash` 模型及思考模式设置；Key 没有打印、提交或加入模型消息。

```text
LLM_MODEL=deepseek-flash
LLM_THINKING=true
LLM_REASONING_EFFORT=low
LLM_JSON_MODE=true
LLM_CONTEXT_TOKENS=32000
```

`LLM_THINKING` 可省略以遵循服务默认值；设置 true/false 时发送 `thinking.type=enabled/disabled`，只应对支持该扩展的服务设置。UI 更新其他连接设置时保留该配置。启用思考后单次输出预算上限 8192 Token，以容纳思考和最终答案，并按剩余上下文扣除输入与安全余量；实际仍受上下文与整局预算限制。

[DeepSeek 思考模式文档](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)说明 `reasoning_content` 与 `content` 分离。程序保留服务返回的原始思考，不回填给其他 agent，也不以程序生成文本冒充缺失的 think。

## 私人决策存档与复盘

模型动作 JSON 增加必填 `decisionReason`，说明信任或怀疑哪个人、为什么选定目标或保留技能。程序验证最终合法动作和非空理由；模型额外返回的顶层非执行元数据只保留在原始响应中，不参与动作，不能覆盖 actor 或规则；动作对象自身仍严格拒绝未知字段。缺失、截断或不合法时只修复一次。服务返回的 think 和最终回答分开保存，修复前后响应都归属于同一最终决策。

每个已被主持人接受的模型动作，在同一个持久化事务中附带：

| 字段 | 用途 |
| --- | --- |
| seat/playerId/name/day/phase/windowId | 绑定 agent 和对应行动窗口 |
| action/source | 最终被规则接受的动作及 model/fallback 来源 |
| model/promptHash | 模型与实际请求消息指纹 |
| decisionReason | 模型对最终动作的私人文本说明 |
| attempts | 原始 content、reasoningContent、响应 ID、结束标志和接收时间 |
| error | 发生默认兜底时记录错误码；不虚构模型理由 |

存档继续采用 UTF-8 JSON 文本事务，已有校验和与原子写入机制。它包含未公开身份和各 agent 思考，应按私人文件管理。进行中的真人投影、其他 agent prompt、跨局反思和 UI 更新不包含决策审计字段。只有整局结束或放弃后，全知复盘接口返回审计数据；可按 agent 筛选、展开决策理由与逐次 think。旧存档没有审计记录时不会补造历史思考。

暂停后的迟到请求不会提交动作或审计；写盘失败会保留包含审计的候选状态并在续玩时重试，不重新调用模型。终局反思仍只使用本人视角，不能读到上帝复盘内容。

## 验证方法

自动化覆盖服务思考与动作分离、缺失理由后的修复、两次响应保留、私有审计读档恢复、复盘门禁，以及真实 Session 接受网络决策后落盘。原有规则、IPC、存储和暂停测试继续执行。

`node scripts/live-smoke.mjs 6` 或 `12` 使用根目录真实配置启动 Electron；真人部分由 UI 自动填写发言和投票，全部其他座位调用真实模型。该脚本会产生服务费用，不属于默认 `npm test`。验证存档保留在被 Git 忽略的 `.local-runs/` 下；脚本只打印统计，不打印 think、回答或 Key。

当前证据：真实 6 人局完整结束，27 次模型决策、27 条 think 响应、0 次默认兜底，覆盖狼人、预言家、女巫和平民；读档后审计内容一致，按 agent 筛选及展开 think 的复盘界面已检查，renderer 错误 0。最新自动化测试统计见下面的最终验证表。

实际 Creator 新规则校验接受 18 位人物描述，2 位使用模板回退；此前未增加性别文字约束时 20 位均接受。

12 人经典局在第 5 日完整结束，覆盖全部六种角色和警长流程。共接受 128 次 AI 动作，其中 123 次由模型完成、5 次为异常兜底；保留 142 条服务 think 响应（含修复和未通过的响应），renderer 错误 0。高强度试跑经历格式拒绝、超时与预算暂停，随后切换低强度配置，扩展验证预算并从存档续玩，最终通过读档审计一致性与复盘 UI 检查。5 次兜底没有冒充模型理由，均有错误码与来源标记。

## 人物性别、身高与外貌

朋友池改为男女各10人，姓名和性别稳定配对；苏晚晴固定为女性。新生成人物的女性身高为158–175cm，男性为168–186cm，采用两次随机值平均减少极端值。这是本游戏的常规人物设定范围，不是对现实身高的限制。外貌涵盖温柔妩媚、明朗灵动、温婉知性、清爽自信，以及开朗儒雅、阳光清爽、沉稳有礼等风格；性别不决定智力或游戏角色。

公开人物数据增加gender字段，桌上座位、朋友列表、介绍与复盘身份标注性别。真人没有指定性别时不代为猜测。启动时自动修正旧朋友池的不合理身高和模板描述，保留ID、姓名和跨局记忆；原对局存档的外貌快照作为历史记录保留，新一局使用修正后的朋友。无需重新初始化才能修复朋友池。Creator提示也要求姓名、性别、身高一致，缺失或违反原事实的生成描述使用安全模板。

读取缺少性别字段的旧对局时，用该对局保留的朋友身份补充公开性别，因此旧对局的人物和复盘标注也可显示男女；不改变已记录的角色或行动。

## 审查与兼容性修复

独立审查的重要问题（输入与输出预算之和可能超上下文）已修复，并通过小上下文回归测试；次要问题（修复请求缺少自己的消息指纹）也已补齐每个响应的 promptHash。审查没有发现私人审计投影泄露或接受动作与审计绑定的并发缺陷。

实测发现高强度思考可能达到输出上限或请求超时，当前 DeepSeek 运行配置采用官方支持的 low 强度，仍保留真实 think。错误、截断和格式修复轨迹如实保留。冗余顶层字段不再触发动作拒绝；真正执行的 action 字段、合法目标、窗口和身份授权校验保持严格。
